# Retinal Fundus Disease Classification

A deep learning project implementing multi-class convolutional neural networks (CNNs) for automated detection and classification of retinal pathologies from color fundus photographs.

## Overview
- **Domain:** Medical Computer Vision / Healthcare AI
- **Frameworks & Libraries:** Python, TensorFlow, Keras, OpenCV, Scikit-learn
- **Techniques:** Transfer Learning (pre-trained architectures), Data Augmentation, Class Imbalance Handling
- **Objective:** Assist early screening of retinal diseases by classifying clinical fundus images into diagnostic categories with confidence metrics.
